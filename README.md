# TypeAhead releases

Downloads for **TypeAhead**, inline AI autocomplete for every text field on macOS, running
entirely on your Mac. By Dutt Mistry and Rohan Bhoi.

**[Download the latest version](https://github.com/duttencodedots/TypeAhead-releases/releases/latest/download/TypeAhead.dmg)**
· [All releases](https://github.com/duttencodedots/TypeAhead-releases/releases)

Requires Apple silicon and macOS 14 or newer.

## Install

1. Open `TypeAhead.dmg` and drag TypeAhead to Applications.
2. Open TypeAhead. If macOS says it cannot verify the app, click **Done**, then go to
   System Settings → Privacy & Security and click **Open Anyway**.
3. Allow TypeAhead in System Settings → Privacy & Security → Accessibility.

From version 0.3.3, TypeAhead finds new versions here by itself: **Check for Updates…** in
its menu installs them in one click.

This repository holds only release downloads.
